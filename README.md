# HTML-CSS
HTML/CSS kurs med 8 kursmoment med 3 stycken betygsgrundande uppgifter: individuellt webbprojekt, agilt grupparbete webbprojekt och muntlig redovisning.

Jag vill tipsa om en plattform som jag gillar för att lära sig HTML-CSS och JavaScript: [Coddy.tech](https://coddy.tech). Den är betald, men man kan lära sig en hel del gratis också. Jag tycker att den är väldigt smidig och bra för att öva på egen hand.
