## Custom skinn färg i VSC

.vscode\settings.json

```json
// HTML/CSS — grön

"workbench.colorCustomizations": {
    "activityBar.background": "#174A2E",
    "titleBar.activeBackground": "#174A2E",
    "statusBar.background": "#174A2E"
}

// JavaScript — Blå

"workbench.colorCustomizations": {
    "activityBar.background": "#174A5F",
    "titleBar.activeBackground": "#174A5F",
    "statusBar.background": "#174A5F"
}

// Python —  Vinröd

"workbench.colorCustomizations": {
    "activityBar.background": "#5A2020",
    "titleBar.activeBackground": "#5A2020",
    "statusBar.background": "#5A2020"
}

// exempel:
{
  // Live Server port
    "liveServer.settings.port": 5501,
  // Blå 
  "workbench.colorCustomizations": {
      "activityBar.background": "#174A5F",
      "titleBar.activeBackground": "#174A5F",
      "statusBar.background": "#174A5F"
  }
}
```
