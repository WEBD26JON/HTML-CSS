# LIA – Min profil och mina mål

**Inriktning:** JavaScript-utveckling, fullstack, API och systemintegration.

**Vad söker jag?**  
En LIA-plats på ett företag som utvecklar mjukvara, tekniska produkter eller integrationslösningar, gärna i Västeråsregionen.

**Vad kan jag bidra med?**  
Jag har praktisk erfarenhet av JavaScript, Node.js, API och IoT genom egna projekt, bland annat elpris.eu och integrationer med Shelly-enheter. Jag är van vid att undersöka tekniska problem och utveckla fungerande lösningar.

**Vad vill jag utveckla?**  
Mina kunskaper inom backend, fullstack-utveckling, API-integrationer och professionell mjukvaruutveckling.

**Mina mål med LIA:**

- Delta i ett verkligt utvecklingsprojekt.
  
- Lära mig företagets utvecklingsprocesser och verktyg.
  
- Bidra med fungerande kod och praktiska lösningar.
  
- Skapa kontakter som kan leda till framtida anställning.
  

**Min strategi:**  
Jag vill kontakta företag där programmering och mjukvaruutveckling är en central del av verksamheten och där jag kan bidra till konkreta projekt.
